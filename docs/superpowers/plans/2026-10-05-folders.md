# Journal folders implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each journal entry live in one optional, user-named folder, with a folder row under the composer that filters the list and decides where new entries are saved.

**Architecture:** The folder is a plain `folder` name on each entry, so IndexedDB stays at version 1 and the backup format stays at schema 1. A new `folders.js` module keeps per-device records of known folders and their latest activity (for ordering and so a folder never vanishes on its own), plus the open folder. `view.js` renders the chip row, the rename/delete panel and the edit-view dropdown. `app.js` holds the new screen state and wires the events.

**Tech Stack:** Native ES modules, no build step, no dependencies. IndexedDB, `localStorage`, a service worker. Tests are throwaway: Node 24 for the pure modules, plus check scripts run in Chrome.

**Spec:** `docs/superpowers/specs/2026-10-04-folders-design.md`

## Global Constraints

- No build step, no package manager, no dependencies, no committed tests. Test files live only in `$T` (defined below).
- IndexedDB `DB_VERSION` stays `1`. Backup `SCHEMA` stays `1`.
- localStorage keys: `journal.folders.v1` holds a JSON array of `{ "name": string, "at": number }`, and `journal.folder.v1` holds the open folder name, `""` for הכל.
- Folder names: trimmed, whitespace runs collapsed to one space, capped at 30 characters, `""` when nothing is left.
- An entry with no folder has no `folder` key. Never store `folder: ""`.
- Only the success path of `submit()` in `app.js` writes to `#composer`. No folder action, render or search may touch it.
- Every value interpolated into HTML goes through `escapeHtml()` in `view.js`, attributes included. No module other than `view.js` touches the DOM. Screen state lives only in `app.js`.
- Mutations keep the shape: store write → `refreshEntries()` → `scheduleAutoSync()`.
- UI strings are Hebrew, hardcoded inline, using exactly the copy in the spec's "Hebrew copy" table.
- CSS lives in the `<style>` block of `index.html`. Use logical properties and only the existing colour tokens. New controls have touch targets at least 44px (`2.75rem`) tall.
- Code comments are Hebrew, matching the surrounding files. Style: 2-space indent, double quotes, semicolons, trailing commas in multi-line literals.
- Work on branch `folders`. Never push: pushing `main` deploys to GitHub Pages.
- Commit messages: a plain imperative subject with no `feat:` prefix, a body that says why, and the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` at the end.

## Review Focus

1. **A real tap on a folder while the new-folder field is open.** A person expects that folder to open on the first tap. A dry run against a prototype showed that closing the field on blur shrinks a sideways-scrolled row between mouse-down and mouse-up, so the click missed. The field now closes only on a tap outside the row, on a folder tap, or on Escape. Pinned by Task 3 (programmatic) and Task 6 part D (real mouse).
2. **A 30-character folder name.** The entry header's label must ellipsize instead of overflowing, the chip row must scroll, and the page must never scroll sideways. Pinned by Task 6 part C.
3. **Switching folders while an entry's edit view is open.** The edit closes like ביטול, the stored entry is unchanged, and the composer draft is untouched. Pinned by Task 4.
4. **A malformed `folder` in a backup file:** a number, whitespace, `null`, an object, a newline, 200 characters. It imports cleanly, either with a cleaned name or with no folder. Pinned by Task 2.
5. **Storage blocked (private mode) or corrupt `journal.folders.v1`.** Folders still work for the session, and junk records are ignored. Pinned by Task 1.

### Task 1: `folders.js`, the folder list, order and naming rule

**Files:**
- Create: `folders.js`
- Test: `$T/harness.mjs`, `$T/folders.test.mjs`

**Interfaces:**
- Consumes: `readLocal(key, fallback)` and `writeLocal(key, value)` from `local-storage.js`. Both already exist.
- Produces (all named exports of `folders.js`):
  - `cleanName(raw: unknown): string`
  - `learn(entries: Entry[]): void`
  - `names(): string[]`, latest activity first
  - `create(raw: string): string`, the clean name or `""`
  - `rename(from: string, to: string): void`, where `to` is already clean
  - `forget(name: string): void`
  - `selected(): string`
  - `select(name: string): void`
  - `matches(entry: Entry, folder: string): boolean`
  - `withFolder(entry: Entry, name: string): Entry`, a copy; `""` removes the key

```js
/* Throwaway test harness for the journal's pure modules. Not committed.
   Installs a fake localStorage before any app module loads, and loads a
   fresh copy of a module per test so module-level state never leaks. */

export const REPO = process.env.REPO ?? "/Users/liorhalfon/git/my-journal-app";

const storage = new Map();
let blocked = false;

Object.defineProperty(globalThis, "localStorage", {
  configurable: true,
  value: {
    getItem(key) {
      if (blocked) throw new Error("storage blocked");
      return storage.has(key) ? storage.get(key) : null;
    },
    setItem(key, value) {
      if (blocked) throw new Error("storage blocked");
      storage.set(key, String(value));
    },
    removeItem(key) {
      if (blocked) throw new Error("storage blocked");
      storage.delete(key);
    },
  },
});

let generation = 0;

/** A fresh instance of `file` (relative to the repo), with storage reset to `seed`. */
export async function load(file, { seed = {}, block = false } = {}) {
  storage.clear();
  for (const [key, value] of Object.entries(seed)) storage.set(key, value);
  blocked = block;
  return import(`${REPO}/${file}?fresh=${generation++}`);
}

/** What the fake localStorage holds right now, as a plain object. */
export function snapshot() {
  return Object.fromEntries(storage);
}

const tests = [];
export const test = (name, fn) => tests.push([name, fn]);

export async function run() {
  let failed = 0;
  for (const [name, fn] of tests) {
    try {
      await fn();
      console.log("ok  ", name);
    } catch (error) {
      failed++;
      console.log("FAIL", name, "\n     ", error.message.split("\n").join("\n      "));
    }
  }
  console.log(`\n${tests.length - failed}/${tests.length} passed`);
  process.exit(failed ? 1 : 0);
}
```

```js
/* יומן — תיקיות.
   התיקייה של רשומה היא שדה `folder` עליה. המודול הזה זוכר אילו תיקיות
   קיימות, מתי נכתב בכל אחת לאחרונה, ואיזו פתוחה. לא נוגע ב-DOM ולא ב-IndexedDB. */

import { readLocal, writeLocal } from "./local-storage.js";

const RECORDS_KEY = "journal.folders.v1";
const SELECTED_KEY = "journal.folder.v1";
const MAX_NAME_LENGTH = 30;

const collate = new Intl.Collator("he").compare;

/* רשומה לכל תיקייה מוכרת: { name, at }, כש-at הוא הפעילות האחרונה בה.
   נשמרת גם כשהתיקייה מתרוקנת, ולכן תיקייה נעלמת רק כשמוחקים אותה.
   הרשימה חיה בזיכרון ו-localStorage רק משמר אותה, כך שבגלישה פרטית
   התיקיות עובדות עד שסוגרים את האפליקציה. */
let records = loadRecords();
let selectedName = readLocal(SELECTED_KEY);

function loadRecords() {
  try {
    const parsed = JSON.parse(readLocal(RECORDS_KEY, "[]"));
    if (!Array.isArray(parsed)) return [];
    return parsed.filter(
      (record) =>
        record &&
        typeof record.name === "string" &&
        record.name &&
        Number.isFinite(record.at)
    );
  } catch {
    return [];
  }
}

function saveRecords() {
  writeLocal(RECORDS_KEY, JSON.stringify(records));
}

function find(name) {
  return records.find((record) => record.name === name);
}

/** כתיבה או עריכה. זה מה שמקדם תיקייה לראש השורה, לא פתיחה שלה. */
function activityOf(entry) {
  return Math.max(entry.createdAtMs || 0, entry.updatedAtMs || 0);
}

/** מסיר רווחים בקצוות, מאחד רווחים כפולים ומגביל ל-30 תווים.
    מחזיר "" כשלא נשאר שם. */
export function cleanName(raw) {
  if (typeof raw !== "string") return "";
  const collapsed = raw.trim().replace(/\s+/g, " ");
  return Array.from(collapsed).slice(0, MAX_NAME_LENGTH).join("").trim();
}

/** מעדכן את הרשימה מתוך הרשומות. נקרא אחרי כל קריאה מהמסד. */
export function learn(entries) {
  let changed = false;
  for (const entry of entries) {
    if (!entry.folder) continue;
    const at = activityOf(entry);
    const record = find(entry.folder);
    if (!record) {
      records.push({ name: entry.folder, at });
      changed = true;
    } else if (at > record.at) {
      record.at = at;
      changed = true;
    }
  }
  if (changed) saveRecords();
}

/** שמות התיקיות, זו שנכתב בה לאחרונה קודם. */
export function names() {
  return [...records]
    .sort((a, b) => b.at - a.at || collate(a.name, b.name))
    .map((record) => record.name);
}

/** תיקייה חדשה נכנסת ראשונה. שם קיים מוחזר בלי לזוז ממקומו. */
export function create(raw) {
  const name = cleanName(raw);
  if (!name) return "";
  if (!find(name)) {
    records.push({ name, at: Date.now() });
    saveRecords();
  }
  return name;
}

/** התיקייה שומרת על מקומה. שם של תיקייה קיימת ממזג את שתיהן. */
export function rename(from, to) {
  const record = find(from);
  if (!record || from === to) return;
  const target = find(to);
  if (target) {
    target.at = Math.max(target.at, record.at);
    records = records.filter((each) => each !== record);
  } else {
    record.name = to;
  }
  saveRecords();
}

export function forget(name) {
  records = records.filter((record) => record.name !== name);
  saveRecords();
}

/** התיקייה הפתוחה, או "" (הכל) אם היא כבר לא קיימת. */
export function selected() {
  return find(selectedName) ? selectedName : "";
}

export function select(name) {
  selectedName = name;
  writeLocal(SELECTED_KEY, name);
}

/** "" היא "הכל", ומתאימה לכל רשומה. */
export function matches(entry, folder) {
  return !folder || entry.folder === folder;
}

/** עותק של הרשומה בתיקייה אחרת. "" מסיר את השדה, שאף פעם לא נשמר ריק. */
export function withFolder(entry, name) {
  const { folder: _previous, ...rest } = entry;
  return name ? { ...rest, folder: name } : rest;
}
```
