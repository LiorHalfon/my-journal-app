# יומן

יומן אישי מינימליסטי. PWA סטטי, בלי שרת ובלי בילד.
הרשומות יושבות ב-IndexedDB בדפדפן שלך. הגיבוי מוצפן בטלפון ועולה למאגר GitHub פרטי.
GitHub מחזיק רק קובץ מוצפן, ולא יכול לקרוא אותו.

```
index.html            שלד + עיצוב
app.js                חיווט: מצב המסך, אירועים, עלייה
entries-store.js      הרשומות ב-IndexedDB
folders.js            תיקיות: אילו קיימות, הסדר שלהן, ואיזו פתוחה
vault.js              המפתח, קוד השחזור וההצפנה
github.js             הקריאות ל-GitHub
backup-store.js       הגדרות הגיבוי ב-IndexedDB
backup.js             עבודת הגיבוי: מתי להעלות, מה להצפין, ואיך לשחזר
backup-file.js        פורמט קובץ הגיבוי
view.js               כל מה שנוגע ל-DOM
local-storage.js      אחסון מקומי שלא זורק
sw.js                 service worker — הדף עובד אופליין
manifest.webmanifest  התקנה כאפליקציה
icons/
```

מודולים נייטיב של הדפדפן (`type="module"`), בלי בילד ובלי תלויות.

## 1. מאגר הגיבוי

הגיבוי הולך למאגר נפרד ופרטי. המאגר של האפליקציה עצמה ציבורי, כי GitHub Pages
בחשבון חינמי דורש את זה, ולכן הוא לא יכול לשמש לגיבוי. האפליקציה מסרבת למאגר ציבורי.

1. ב-GitHub צור מאגר חדש, **Private**.
2. צור טוקן: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - תחת *Repository access* בחר **Only select repositories**, ובחר רק את המאגר הזה.
   - תחת *Repository permissions* תן ל-**Contents** את **Read and write**. שום הרשאה אחרת.
   - בחר תוקף. כשהטוקן פג הגיבוי נעצר, וגיבוי ידני יגיד ליצור טוקן חדש.
3. באפליקציה, בגיליון הגיבוי, לחץ **יצירת מפתח** ושמור את קוד השחזור במנהל הסיסמאות.
   במכשיר חדש, או אחרי התקנה מחדש, לחץ **יש לי קוד שחזור** והדבק את אותו קוד.
4. תחת **מאגר GitHub** הדבק `owner/repo` ואת הטוקן. בכל מכשיר בנפרד.

## 2. הרצה מקומית

service worker ו-WebCrypto דורשים origin מאובטח. `file://` לא יעבוד.

```bash
cd my-journal-app
python3 -m http.server 8080
```

ואז `http://localhost:8080` — localhost נחשב secure context, אז הכל עובד.

## 3. פריסה

כל אחסון סטטי. GitHub Pages, Netlify, Cloudflare Pages — העלה את התיקייה כמו שהיא.
תנאי אחד: **HTTPS**. בלעדיו אין service worker ואין הצפנה.

שים לב ל-origin: ב-GitHub Pages כל הריפואים תחת אותו חשבון חולקים
`https://liorhalfon.github.io`, אז מקור אחד מכסה את כולם.

## 4. התקנה בנייד

פתח את הכתובת, ואז "הוסף למסך הבית". מכאן זה נפתח במסך מלא, בלי סרגל דפדפן,
ועובד גם בלי רשת.

## גיבוי

הגיבוי רץ לבד: כשהאפליקציה נפתחת, כשהיא יוצאת לרקע או חוזרת ממנו, כשהרשת חוזרת,
ו-20 שניות אחרי שינוי. הוא מעלה רק אם היומן השתנה מאז ההעלאה הקודמת. גיבוי אוטומטי
שנכשל לא מציג כלום: הרשומות שמורות במכשיר, והפעם הבאה תנסה שוב. **גיבוי עכשיו**
מעלה מיד, ומציג את השגיאה אם יש.

- **גרסאות.** כל העלאה היא commit עם ההודעה `backup`, אז ההיסטוריה של המאגר היא רשימת הגרסאות.
- **שחזור.** מוסיף מגרסה רשומות שחסרות במכשיר, לפי `id`. לא מוחק, לא דורס ולא משכפל.
- **אחרי 3 ימים** בלי גיבוי מאושר הנקודה בכותרת נהיית אדומה. יומן שלא השתנה נחשב מגובה,
  אז האדום אומר ששינויים לא מצליחים לצאת, לא שסתם היה שבוע שקט.

יש גם ייצוא וייבוא לקובץ מקומי, בלי רשת.

הקובץ במאגר הוא `journal.sealed.json`. הוא מוצפן ב-AES-256-GCM בטלפון, לפני שהוא יוצא:

```json
{"app":"tiny-journal","sealed":1,"kid":"1a2b3c4d","iv":"...","data":"..."}
```

`kid` מזהה את המפתח, כך שהאפליקציה מבדילה בין "הוצפן במפתח אחר" ל"קובץ פגום".
`iv` חדש בכל הצפנה. `data` הוא קובץ הגיבוי המוצפן.

קובץ הגיבוי, לפני ההצפנה:

```json
{
  "app": "tiny-journal",
  "schema": 1,
  "exportedAt": "2026-09-01T09:16:30.000Z",
  "count": 2,
  "entries": [
    { "id": "e...", "text": "...", "createdAt": "...", "createdAtMs": 0, "folder": "בריאות" }
  ]
}
```

`folder` אופציונלי: רשומה בלי תיקייה פשוט בלי השדה, וקבצים מלפני התיקיות נקראים כמו שהם.

## דברים ששווה לדעת

**מחיקת נתוני האתר מוחקת את היומן.** IndexedDB הוא אחסון דפדפן. "נקה נתוני גלישה"
מוחק הכל. זה בדיוק מה שהגיבוי קיים בשבילו — אל תדלג עליו.

**iOS מוחק אחסון של אתרים שלא נגעת בהם.** Safari מפנה אחסון אחרי כשבועיים
של אי-שימוש באתר. אפליקציה שהותקנה למסך הבית פטורה מזה, אבל אם אתה מתכוון
להשתמש דרך הדפדפן, ודא שהגיבוי רץ.

**האפליקציה בנויה למכשיר כותב אחד.** הגיבוי רק מעלה, ולא ממזג. מכשיר שני שמגבה
לאותו מאגר יעלה את היומן שלו מעל הגרסה של הראשון. הגרסה הקודמת נשארת בהיסטוריה.
מכשיר חדש שמוצא גיבוי במאגר לא מעלה עליו: הוא מבקש לשחזר קודם, ורק אז ממשיך לגבות.
`id` נוצר במכשיר, ולכן השחזור ממזג בלי התנגשויות.

**שינויים בתיקיות לא עוברים למכשיר אחר.** שחזור לא דורס רשומה שכבר קיימת,
ולכן שינוי שם של תיקייה, מחיקה שלה או העברת רשומה לתיקייה אחרת לא יגיעו
לרשומות שכבר יושבות במכשיר השני. אחרי שינוי שם, המכשיר השני יראה את שני
השמות עד שתשנה את השם גם שם. תיקייה ריקה קיימת רק במכשיר שבו יצרת אותה.

**שמור את קוד השחזור.** המפתח נוצר בטלפון ונשמר בו כך שאי אפשר להוציא אותו.
קוד השחזור הוא העותק היחיד שלו מחוץ לטלפון. בלי הקוד ובלי הטלפון אי אפשר לפתוח את
הגיבוי, ואף אחד לא יכול לאפס אותו. אחרי "העתקה" הקוד נשאר בהיסטוריית הלוח של אנדרואיד,
אז מחק אותו משם אחרי ששמרת אותו.

**בטלפון עצמו הרשומות לא מוצפנות.** הן יושבות ב-IndexedDB כמו קודם. ההצפנה שומרת
על הגיבוי, לא על טלפון פתוח.
